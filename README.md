# Azure Storage Explorer and SAS Token Governance

Tools and workflows for exploring Azure Storage accounts and governing Shared Access Signature (SAS) tokens—creation, validation, expiry tracking, and least-privilege access.

## Features

- Browse storage accounts, containers, and blobs
- Generate and review SAS tokens with scoped permissions
- Track token lifecycle and governance policies

## Getting started

Add your application source to this repository, then install dependencies and run the project per your stack (see docs in your solution).

## Security

Do not commit connection strings, account keys, or SAS tokens. Use environment variables or Azure Key Vault for secrets.
